# goit-markup-hw-01

Навчальний проєкт у межах курсу **GoIT** — HTML-розмітка лендингу **WebStudio**.
Завдання присвячене семантичній верстці сторінки за макетом без стилізації (CSS).

**Демо:** https://marynashavlak.github.io/goit-markup-hw-01/

## Опис

Сторінка побудована з дотриманням семантики HTML та складається з таких блоків:

- **Header** — логотип, навігація (`<nav>`) та контакти (`<address>`)
- **Hero** — головний заголовок і кнопка `Order Service`
- **Our Features** — перелік переваг компанії
- **Our Team** — картки членів команди із зображеннями
- **Footer** — логотип та опис компанії

## Технології

- HTML5 (семантична розмітка)
- [Prettier](https://prettier.io/) — форматування коду

## Структура

```
goit-markup-hw-01/
├── images/          # зображення команди (.jpg)
├── index.html       # головна сторінка
├── .prettierrc.json # конфігурація Prettier

```
