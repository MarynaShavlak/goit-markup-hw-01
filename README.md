# goit-markup-hw-01

Навчальний проєкт у межах курсу **GoIT** — HTML-розмітка лендингу **WebStudio**.
Завдання присвячене семантичній верстці сторінки за макетом без стилізації
(CSS).

**Демо:** https://marynashavlak.github.io/goit-markup-hw-01/

## Опис

Сторінка побудована за макетом із дотриманням семантики HTML та складається з
таких блоків:

- **Header** — логотип `WebStudio`, навігація (`<nav>`) з посиланнями
  **Features**, **Team**, **Portfolio** та контакти (`<address>`) — пошта й
  телефон
- **Hero** — заголовок «Effective Solutions for Your Business» і кнопка
  `Order Service`
- **Features** — чотири переваги компанії: Strategy, Punctuality, Diligence,
  Technologies
- **Our Team** — картки членів команди (Mark Guerrero, Tom Ford, Camila Garcia,
  Daniel Wilson) із фото та посадами
- **Footer** — логотип `WebStudio` та короткий опис компанії

## Технології

- HTML5 (семантична розмітка)
- [Prettier](https://prettier.io/) — форматування коду
